# Super Mario Bros Embarqué — Projet Individuel 2025–2026

## Objectif

Concevoir une console portable autonome reproduisant un niveau simplifié de Super Mario Bros, avec :

- affichage LCD
- scroll horizontal
- déplacements + collisions
- obstacles/ennemis
- sons (buzzer)
- gyroscope
- boîtier 3D imprimé

## Matériel (fourni)

- microcontrôleur
- écran LCD
- gyroscope
- buzzer
- batterie

## Planning global (initial)

- Phase 1 : Organisation
- Phase 2 : Schéma électronique
- Phase 3 : Programmation du jeu
- Phase 4 : Gyroscope + sons
- Phase 5 : Boîtier 3D
- Phase 6 : Assemblage
- Phase 7 : Tests
- Phase 8 : Documentation + Soutenance

## Technologies utilisées

Arduino / C++, Git, Trello, Fusion360 (ou SolidWorks)
